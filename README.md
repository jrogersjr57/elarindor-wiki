# Worldbuilding

A centralized repository for creating, organizing, and evolving multiple worldbuilding projects.

This repository functions as both a creative workshop (for developing ideas) and a codex (for maintaining structured, readable lore).

---

## Purpose

This repository is designed to:

- Capture raw ideas and inspiration
- Develop and refine worldbuilding concepts
- Organize structured lore across multiple worlds
- Maintain a long-term, version-controlled archive of creative work

Content ranges from early drafts to more developed, “canon” material.

---

## Repository Structure

### 🌍 Worlds
Contains all world-specific content.

Each world follows a consistent structure:

- Races  
- Cultures  
- Locations  
- Magic  
- Creatures  
- History  
- Notes  

Example:
/Worlds/Elarindor/Races/Valdari.md

---

### 🔁 Shared
Reusable ideas and systems that may apply across multiple worlds.

- Systems (e.g., magic frameworks)
- Creatures (general concepts)
- Worldbuilding mechanics

---

### 💭 Concepts
Raw or unassigned ideas not yet tied to a specific world.

- Unsorted  
- To-Develop  
- In-Progress  

---

### 🛠️ Projects
Specific creative efforts such as:

- Scenes  
- Stories  
- Epic battles  
- Experiments  

---

### ⚙️ System
Templates, guides, and workflow support.

---

## Workflow

Use the following development flow:

1. Capture ideas in /Concepts/Unsorted
2. Move to /Concepts/To-Develop when worth exploring
3. Refine in /Concepts/In-Progress or move into a World
4. Expand within /Worlds/<WorldName>/...
5. Mark as Canon when stable

---

## Content Status

Each file should include a status header:

- Draft – Early idea  
- In-Progress – Actively developing  
- Canon – Stable, but still editable  

Example:

World: Elarindor   Status: In-Progress   Tags: #race #magic #culture

---

## Core Philosophy

- Ideas evolve—nothing is permanently fixed  
- Structure supports creativity, not restricts it  
- Separate raw thinking from refined lore  
- Build systems, not just individual ideas
